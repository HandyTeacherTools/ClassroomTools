How to Use the KWL Chart

The KWL Chart is a classic learning framework — Know, Want to Know, Learned — brought to life as a live projected display. Start by typing your topic name in the field at the top. Then add student responses to each column by typing in the input box at the bottom of that column and clicking Add (or pressing Enter). Items appear as bullet points and can be clicked to edit inline. Remove any item by hovering and clicking the × button. Use the chart at the start of a lesson to activate prior knowledge (K column) and surface questions (W column), then return at the end to fill in what was learned (L column). Click Print to send the completed chart to your printer as a clean document, Copy Text to paste it into a document, or Clear All to reset for a new topic. The three-column layout is designed to be readable from the back of a classroom.
