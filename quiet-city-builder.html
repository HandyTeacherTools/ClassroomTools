Quiet City Builder

Press Start listening

The city only grows during quiet time, and it is saved in this browser so the class can keep building it across days. The microphone only measures volume. Nothing is recorded or sent anywhere.

Classroom ideas
  • Click Calibrate to quiet room while the class works silently for 3 seconds.
  • Set a goal: finish the whole city by Friday, using the quiet work periods each day.
  • Use the build speed to match the activity: fast for a short work period, slow for a week-long city.
